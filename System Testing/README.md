## FoneCall Testing 
FoneCall was tested on Windows 10.0.19045. The testing methodology combined verification of all UI components working as designed and AL assisted unit testing of the underlying code. The testing methodology was designed to ensure that FoneCall functions as designed and that all UI components are working toeether as expected.

It is installed on my machine, tested with the official scrcpy.exe v5.0.1 from the official scrcpy project page and I use it daily.  The specific unit test detail is provided in the [Unit Test Folder](https://github.com/ddDerelict/FoneCall/UnitTesting)

FoneCall passed all unit tests and is ready for use.  The testing methodology and results are provided here for transparency and to provide a reference for future testing.
